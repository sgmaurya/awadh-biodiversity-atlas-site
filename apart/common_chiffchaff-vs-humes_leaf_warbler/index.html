How to tell them apart कैसे पहचानें

Hume's Leaf Warbler, as the Common Chiffchaff profile puts it

Hume's Leaf Warbler]] (Phylloscopus humei)

Darker ear-coverts; pale eyebrow stripe; smaller

Common Chiffchaff: Common Chiffchaff is identified by dark legs and the distinctive chiff-chaff song. If the bird has pale legs, it is a Willow Warbler. If it has a clear eyebrow stripe, it is a different species.

Hume's Leaf Warbler: Hume's Leaf Warbler is a tiny greenish warbler with a pale eyebrow stripe and white underparts, restlessly gleaning in vegetation. If the bird is grey with a black ear patch, it is Lesser Whitethroat. If it shows a yellow wing-bar or yellow-tinged underparts, it is a different species.
