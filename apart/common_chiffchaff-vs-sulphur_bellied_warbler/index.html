How to tell them apart कैसे पहचानें

Common Chiffchaff, as the Sulphur-bellied Warbler profile puts it

Phylloscopus collybita

Dull greyish-olive above, dingy buffy-white below without sulphur-yellow; constantly dips tail

Common Chiffchaff: Common Chiffchaff is identified by dark legs and the distinctive chiff-chaff song. If the bird has pale legs, it is a Willow Warbler. If it has a clear eyebrow stripe, it is a different species.

Sulphur-bellied Warbler: Rock-dwelling warbler with dull earthy-brown upperparts, vivid sulphur-yellow underparts, and long bright yellow eyebrow.
