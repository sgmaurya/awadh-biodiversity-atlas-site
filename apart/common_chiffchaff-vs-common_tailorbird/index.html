How to tell them apart कैसे पहचानें

Common Chiffchaff, as the Common Tailorbird profile puts it

Common Chiffchaff]] (Phylloscopus collybita)

Winter visitor; olive-brown overall, no rufous cap, different call

Common Chiffchaff: Common Chiffchaff is identified by dark legs and the distinctive chiff-chaff song. If the bird has pale legs, it is a Willow Warbler. If it has a clear eyebrow stripe, it is a different species.
